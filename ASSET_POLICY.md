# ASSET POLICY

## Goal

Keep the project legally clean and web-performant.

## Allowed

- original assets created for the project;
- procedural primitives;
- CC0 assets;
- public-domain assets;
- permissively licensed assets whose attribution requirements are satisfied.

## Required provenance fields

For every external asset:

- filename;
- creator/source;
- source location;
- license;
- modifications;
- date acquired.

Record in `ASSET_PROVENANCE.md`.

## Forbidden

- ripped assets from commercial games;
- Disney Alice visual assets;
- movie screenshots as game textures;
- copyrighted music without permission;
- unlicensed font redistribution;
- ambiguous "found on Google" material.

## Web constraints

- optimize meshes;
- resize textures intentionally;
- use compressed formats where supported by chosen pipeline;
- avoid committing giant source files to ordinary Git history;
- if large source assets become necessary, define a deliberate large-asset strategy first.

## Placeholder rule

A simple original placeholder is better than legally questionable production art.
