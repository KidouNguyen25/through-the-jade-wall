# START HERE — AI Autonomous Development Kit

## Project

**Through the Jade Wall**

A browser-first 3D narrative puzzle game where an Alice-like journey through an impossible city is governed by Mahjong logic. The player explores a dream-city, reconstructs contradictory memories, and learns that the 144 tiles are not collectibles: they are the city's laws, identities, and fragments of truth.

This kit is written so an autonomous coding AI can initialize the repository, plan work, implement vertical slices, test, commit, push, open pull requests, and deploy a production build without improvising the product direction.

## Non-negotiable product rules

- Browser-first; deployable to GitHub Pages.
- No backend required for the first playable release.
- Third-person 3D exploration and environmental puzzle solving.
- Mahjong is a world rule system, not a decorative theme.
- Alice influence means dream logic, identity instability, paradox, scale, impossible spaces, linguistic logic, and curiosity. Do not imitate Disney visual identity or modern copyrighted adaptations.
- The first release is a polished vertical slice, not an unfinished open world.
- Performance is a feature. The game must remain playable on ordinary student laptops and modern mobile-class GPUs where practical.
- Every feature must have a testable acceptance criterion.
- `main` must remain releasable.

## Definition of the first public success

A new player can open the GitHub Pages URL and complete a 20–30 minute vertical slice containing:

- opening tea-house scene;
- one explorable district;
- one Mahjong environmental mechanic;
- one memory reconstruction;
- one hostile “Dead Hand” encounter;
- one boss-puzzle;
- one meaningful narrative choice;
- save/load;
- keyboard/mouse controls;
- production build with no console errors.

## AI operating principle

Do not maximize amount of code. Maximize playable value per change while preserving architecture and testability.
